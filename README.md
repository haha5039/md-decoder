# 마스터듀얼 카드 디코더

[배포된 사이트](https://haha5039.github.io/md-decoder/) · 카드 디코더 이벤트의 공개 정보와 O/X 판정으로 후보를 좁히고 다음 제출을 추천하는 웹 도구입니다.

## 사용법

1. 게임에서 공개된 값을 **정답 카드 확실한 정보**에 입력합니다. 효과와 효과/펜듈럼처럼 복합 프레임을 정확히 구분하세요.
2. 제출한 카드를 검색하고 6개 항목의 O/X만 기록합니다. 프레임·레벨이 O면 제출 카드의 값을 공개값으로 자동 반영합니다.
3. **최적의 카드 계산**으로 추천을 확인합니다. 남은 도전이 1회라면 즉시 정답 확률, 후보가 60장 이하이고 도전이 2회 이상이면 2회 내 성공 확률을 자동 선택합니다. 기준은 직접 바꿀 수 있습니다.
4. 잘못된 입력은 **되돌리기** 또는 단서 옆 삭제 버튼으로 해당 입력 묶음을 취소합니다. 실제로 차감한 도전 횟수만 환급합니다.

추론 내용과 남은 횟수는 이 브라우저에 자동 저장됩니다. 초기화하면 기본값(도전 4, 힌트 1)으로 돌아갑니다. 남은 횟수는 실제 게임에 맞게 수정하세요. 후보 목록은 검색하거나 48장씩 더 볼 수 있습니다. 추천 카드는 화면에 맞는 열 수만 한 줄로 표시됩니다.

## 이벤트 규칙과 데이터

- 프레임, 속성, 레벨/랭크/링크, 종족, 공격력, 수비력을 비교합니다.
- 도전 판정에서는 펜듈럼 프레임 중 한 부분만 겹쳐도 일치합니다. 공개된 정답 프레임을 입력할 때는 정확히 일치하는 후보만 남깁니다.
- 촐킨·비시바르킨·FNo.0/SNo.0 계열은 인쇄 수치와 룰상 수치 모두로 판정하고, 룰상 수치를 공개합니다.
- 모든 항목이 일치하는 카드는 이름이 달라도 정답으로 취급합니다. 한 번 제출한 카드는 다시 차감하지 않습니다.
- `?`는 미정 공격력/수비력(-1), `없음`은 링크 몬스터 등의 수비력 부재(null)로 구분합니다.

2026-09-26 내장 데이터는 몬스터 **9,058장**, 순수 효과 프레임 **5,796장**입니다. 사용자가 확인한 인게임 수치와 일치합니다. 전체 카드 목록의 개별 포함 여부까지 검증한 것은 아니며, 이벤트에는 일부 제외 카드가 있을 수 있습니다.

데이터는 [YGOPRODeck API](https://db.ygoprodeck.com/api/v7/cardinfo.php?format=Master%20Duel)의 Master Duel 목록을 사용합니다. 업데이트 시 API의 프레임을 보존하고, 빈 응답·잘못된 스테이터스·과도한 카드 수 감소를 거부합니다. 한국어 요청만 실패하면 기존 번역을 유지합니다. 이벤트 시작 뒤 추가된 카드까지 갱신될 수 있으므로 최신 API 목록과 이벤트 목록이 항상 같지는 않습니다.

플레이 모드는 **횟수 제한 없는 연습 모드**입니다. 일일 지급·보너스 힌트 발동·보상은 재현하지 않습니다.

## 추천 알고리즘

모든 후보가 같은 확률로 정답이라고 가정합니다. 추천 계산과 후보 갱신은 화면에서 입력하는 6개 O/X를 동일하게 사용하며, 성공은 하나의 종료 결과로 처리합니다.

| 지표 | 의미 |
|---|---|
| 기대 정보량 | 공개 결과별 후보 분포의 Shannon entropy 최대화 |
| 최악 잔여 최소 | 실패 시 최대 잔여 후보 수 최소화 |
| 평균 잔여 최소 | 결과별 후보 수 제곱 합 / 전체 후보 수 최소화; 성공은 잔여 0 |
| 즉시 정답 확률 | 이번 제출로 6항목 모두 일치하는 후보의 비중 |
| 2회 내 성공 확률 | 첫 제출 성공 + 실패 결과별 최선의 다음 제출 성공; 후보 60장 이하에서 전수 계산 |

2회 내 확률은 추가 유료·보너스 힌트를 쓰지 않는 조건입니다. 공개 힌트의 예상 잔여 수는 미공개 항목이 균등하게 선택된다는 가정입니다. 여러 문제 사이의 자원 배분이나 보상 최적화는 계산하지 않습니다. 엔트로피나 평균 잔여 최소가 전체 해결 횟수의 최적성을 보장하지는 않습니다.

동일한 판정·공개 결과를 만드는 카드의 계산을 공유하면서 카드 수 가중치를 유지합니다. 펜듈럼의 부분 일치를 동치관계로 취급하지 않습니다. 프레임·레벨을 비트마스크로 전처리하고 Web Worker에서 계산해 화면 입력을 막지 않습니다. 후보가 변경되면 진행 중인 계산을 취소합니다. 후보 밖 카드도 정답 인정 가능성이 있으면 정답 추천에 포함합니다.

## 개발 및 검증

Node.js 22.12 이상을 권장합니다.

```bash
npm install
npm run dev
npm test
npm run build
npm run evaluate -- 12
npm run compare -- 12
npm run data:update
```

기본 접속 주소: [http://localhost:5173/md-decoder/](http://localhost:5173/md-decoder/).

프로젝트를 수정한 뒤에는 개발 서버를 다시 시작하고 접속 여부를 확인합니다. GitHub Actions에서도 테스트 성공 후 빌드합니다.

`src/utils.js`의 공통 판정, `src/solver.js`의 추천 엔진을 도우미·플레이·시뮬레이션이 공유합니다. 시뮬레이션은 고정 시드와 동일한 정답/초기 힌트로 각 전략을 비교하고, 최대 8회에서 종료합니다. 실패를 성공 평균에 섞지 않고 실패 수, 단순화로 정답이 제거된 수, 2·3·4회 내 성공률, 성공 사례 평균·95백분위 횟수, 계산 시간을 보고합니다. 표본이 적은 결과를 전체 이벤트 성능으로 해석하지 마세요.

순수 함수 회귀 테스트는 프레임 수치, 특수 레벨, 공개 정보 반영, 즉시/2회 성공률, 중복 프로필 가중치, 전수 기준 구현과의 일치, 데이터 검증 및 자원 환급을 검사합니다.

개인 연구용 비공식 도구이며 코나미와 무관합니다.
